# RocoPlayer v0.2.1

原「弦序」更名为 **RocoPlayer**，本版汇总 0.2.0 的界面与在线谱库功能，以及 0.2.1 的提示自动关闭优化。

## 更新

- 简化主界面，九键映射默认折叠，保留常驻播放控制和置顶小窗。
- 接入 RocoMusic 洛克乐谱：搜索曲名/作者、浏览最新、分页、一键下载公开 MIDI 到本地谱库。
- 下载保留原谱并适配当前九键映射，支持取消、错误提示和同版本重复检测，不会自动演奏。
- 成功和已取消提示在 3 秒后自动消失；进行中任务和错误提示保持可见。
- 沿用原应用标识和数据目录，继续读取现有曲库及设置。
- 保留 DD 初始化 Win 键防护与自动连播 3 秒曲间间隔。

## 安装

下载 `RocoPlayer_0.2.1_x64-setup.exe`，保存内容并正常退出旧播放器后再安装。安装包包含运行环境、模型和 DD 组件，安装后从快捷方式启动，无需启动脚本或另装 Python/Node/Rust。

附 `SHA256SUMS.txt` 用于校验下载完整性。应用安装包未签名，可能触发 SmartScreen。DD 安装如提示重启，请按提示处理。

## 验证与限制

- Python 回归测试 208 项（204 通过、4 跳过）；前端 22 项测试及 TypeScript 检查通过。
- 独立打包引擎通过启动/关闭检查；在线下载入库已在隔离库验证，不发送真实按键。
- 在线谱库目前依赖网站公开页面及下载入口；网站结构变化时可能需要更新客户端。暂只支持公开 MIDI，不处理付费或登录授权内容。
- 未完成干净 Windows 虚拟机安装、升级、卸载验收；继续作为预览版发布。

仓库已更名为 [Einzieg/RocoPlayer](https://github.com/Einzieg/RocoPlayer)。个人曲库、音频及本地调试产物不随源码发布。
