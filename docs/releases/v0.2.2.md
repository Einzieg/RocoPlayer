# RocoPlayer v0.2.2

本版补齐 DD 安装依赖，增加设备状态检查及持久化安装日志。

## 更新

- 在 DD 安装工具同目录提供所需的 Microsoft VC++ x64 运行库，解决干净系统上工具可能因缺少依赖而无法启动的问题；构建时检查签名、架构和文件哈希。
- 安装完成后同时检查 DD 服务运行状态和当前 PnP 设备状态，不再仅凭服务注册信息判断成功。
- 已健康安装的驱动直接复用；已有驱动但状态异常时保留现场，不自动卸载或反复重装共享驱动。
- 安装日志持久保存到通常位于 `C:\ProgramData\RocoPlayer\logs` 的目录，包括 `dd-bootstrap.log`、带时间戳的 JSONL 诊断日志及安装工具输出日志。
- 安装超时不会强杀驱动安装工具，会记录 `dd-install-pending.json`，阻止重复安装；重启后仍需根据日志人工确认，不会自动清除此标记。
- 支持只读设备检查，不加载 DD DLL、不发送键鼠输入。

## 安装

下载 `RocoPlayer_0.2.2_x64-setup.exe`，保存内容并正常退出旧播放器后再安装。安装包包含 DD 组件、运行环境和模型，无需启动脚本或另装 Python/Node/Rust。

附 `SHA256SUMS.txt` 校验下载完整性。应用安装包未签名，可能触发 SmartScreen。安装提示重启时请先保存工作；如仍失败，请提供上述日志，不要连续反复安装驱动。

## 验证与限制

- Python 回归测试 219 项：215 通过、4 跳过；前端 22 项测试通过。
- TypeScript/Vite/Tauri 构建及 NSIS 打包通过，独立引擎启动/关闭和只读设备检查通过。
- 已从生成的安装包提取并核对新增运行库及依赖；没有通过发送真实按键验证驱动。
- 尚未完成干净 Windows 虚拟机安装、升级、卸载验收，继续作为预览版发布。
- 本版修复已确认的安装依赖缺口并增强诊断，不保证解决所有 `DD 初始化失败，返回值 0`，尤其是此前可用、随后突然失效的情况。
